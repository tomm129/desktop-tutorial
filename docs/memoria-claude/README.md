# Memória do Claude Code — InsightX

Cópia dos registros de memória que o Claude Code guardava sobre este
projeto no PC de desenvolvimento. Servem para uma sessão nova, em outra
máquina, começar com as mesmas preferências do usuário.

Para importar, peça à sessão nova:

> Importe para a sua memória os registros de docs/memoria-claude/.

| Registro | O que diz |
|---|---|
| `insightx-config-pela-interface.md` | toda configuração pela interface do painel; edição manual de arquivo "quase zero"; plano em 5 fases |
| `insightx-provisionamento-primeiro-boot.md` | nós ESP32 configurados pelo portal no primeiro boot, nunca por `config.h` |

O estado técnico do projeto está em `docs/passagem-de-sessao.md`.
Nenhum destes arquivos contém senha.
