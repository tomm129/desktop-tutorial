# Brawl Coop — Protótipo

Protótipo inicial de um jogo cooperativo top-down (estilo Brawl Stars), feito na **Godot Engine 4**.

## Como rodar

1. Baixe a Godot Engine (versão **4.3** ou mais nova) em https://godotengine.org/download
   — é um único arquivo, não precisa instalar nada.
2. Abra a Godot, clique em **Import**, e selecione o arquivo `project.godot` desta pasta (`brawl-coop`).
3. Clique no botão de **Play** (▶, canto superior direito) ou aperte **F5**.

## Controles

| Ação    | Tecla / botão            |
|---------|--------------------------|
| Andar   | **W A S D**              |
| Mirar   | mover o **mouse**        |
| Atirar  | **botão esquerdo** do mouse |

## O que já funciona

- Um jogador que anda pela arena.
- Mira que acompanha o mouse.
- Tiro em rajada (segurar o botão).
